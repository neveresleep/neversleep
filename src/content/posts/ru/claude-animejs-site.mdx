Минимальный сайт с плавными анимациями выглядит дороже, чем стоит. Текст «выезжает» по буквам, фигуры двигаются по таймлайну, курсор живой. Раньше для этого надо было знать GSAP и пилить вручную. Сейчас задаёшь промпт Claude — он генерит код под библиотеку [Anime.js](https://animejs.com/), ты копируешь и запускаешь.

Это не «вайб-кодинг ради вайба»: вся механика в Anime.js — это короткие декларативные вызовы. Claude хорошо их пишет, потому что синтаксис стабильный, документация чистая.

## Что нужно

- Claude (claude.ai или Claude Code в терминале)
- Node.js установлен на компе ([nodejs.org](https://nodejs.org/), любой LTS)
- Любой редактор кода (VS Code, Cursor, Zed)
- 30–60 минут

## Шаг 1. Попроси Claude спланировать сайт

Не пиши «сделай сайт с анимациями» — получишь шаблон. Опиши вайб конкретно. Промпт:

```
Спланируй минималистичный одностраничный сайт с плавными
анимациями в стиле сайта Anime.js. Стек: HTML + CSS + Anime.js
(без React, без сборщиков). Что должно быть на странице:
— большой hero-заголовок с анимацией появления по буквам
— секция «features» из 3 блоков, появляется по скроллу с stagger
— hover-эффект на блоках (лёгкий tilt + изменение цвета)
— кастомный курсор, который притягивается к кликабельным
  элементам
— футер с минимальной информацией

Опиши структуру файлов и порядок реализации, без кода. Я скажу
«пишем», когда буду готов.
```

Claude вернёт план: `index.html`, `styles.css`, `main.js`, какие анимации в каком порядке делать. Если что-то лишнее — режь сразу: «убери features, оставь hero и курсор».

## Шаг 2. Создай папку и поставь Anime.js

Открой терминал, создай папку проекта и поставь библиотеку:

```bash
mkdir my-anime-site && cd my-anime-site
npm init -y
npm i animejs
```

`npm init -y` создаёт `package.json` без вопросов. `npm i animejs` тянет последнюю версию Anime.js в `node_modules`.

Если терминал ругается «command not found: npm» — значит Node.js не установлен. Поставь с [nodejs.org](https://nodejs.org/), перезапусти терминал.

## Шаг 3. Сгенерируй базовый HTML и CSS

Промпт Claude:

```
Создай index.html и styles.css по плану выше. Шрифт — Inter с
Google Fonts. Цвета: фон #0F0F12, текст #F4F4F5, акцент
#3DD68C. Hero на весь экран, заголовок 96px на десктопе, 48px
на мобиле. Никаких рамок и теней — только типографика и
пространство.
```

Скопируй оба файла в папку проекта. Открой `index.html` двойным кликом — увидишь статику без анимаций.

## Шаг 4. Попроси Claude таймлайны и stagger

Это ядро Anime.js. Таймлайн — последовательность анимаций; stagger — задержка между элементами в группе. Промпт:

```
Сгенерируй main.js. Импортируй anime из 'animejs/lib/anime.es.js'.
Сделай:
1) Hero-заголовок: разбей на span-буквы, появление с
   translateY(40px → 0) и opacity (0 → 1), stagger 30ms,
   easing 'easeOutExpo', duration 800ms.
2) Блоки features: появление по скроллу через
   IntersectionObserver, stagger 120ms, scale (0.95 → 1) +
   opacity, easing 'easeOutCubic'.
3) Запусти hero сразу при загрузке.

Используй ES-модули (type="module" в HTML). Покажи правки в
index.html, если нужны.
```

Claude вернёт код. Подключи `main.js` через `<script type="module" src="main.js"></script>`. Перезагрузи `index.html` — заголовок «выезжает» по буквам, блоки появляются на скролле.

## Шаг 5. Hover, курсор, скролл

Добавь интерактив одним промптом:

```
В тот же main.js добавь:
1) Hover на каждом блоке features: tilt по mousemove (rotateX
   и rotateY от позиции курсора, max 8deg), плавный возврат на
   mouseleave (300ms easeOutQuad).
2) Кастомный курсор: круг 12px, следует за мышью с lerp
   (плавность 0.15). При наведении на ссылку или кнопку —
   увеличивается до 32px и меняет цвет на акцентный.
3) Скрывай нативный курсор (cursor: none на body).

Не ломай анимации с шага 4.
```

После этого сайт ощущается живым: блоки реагируют на наклон, курсор «магнитится» к кнопкам.

## Шаг 6. Чисти UI до минимума

Соблазн добавить градиенты, эмодзи, иконки — задави. Правило: **движение работает только когда вокруг тишина**. Удали всё лишнее: рамки, тени, цветовые акценты сверх одного. Оставь типографику, пустое место и анимацию.

## Что может пойти не так

- **Анимация дёргается на мобиле.** Anime.js дёшево анимирует `transform` и `opacity`, дорого — `width`, `height`, `top`, `left`. Если Claude сгенерил второе — попроси переписать на transform.
- **Курсор «отстаёт».** Уменьши коэффициент lerp (0.2 → 0.3) или добавь `requestAnimationFrame` напрямую, а не `setInterval`.
- **Stagger ломается на длинных текстах.** Если букв > 80, увеличь `delay` между ними или раздели на слова.
- **Сайт не открывается через двойной клик.** Браузеры блокируют ES-модули по `file://`. Запускай локальный сервер: `npx serve` в папке проекта.

## Что попробовать дальше

- Добавь SVG-иллюстрации и анимируй их через Anime.js (`stroke-dashoffset` для рисующихся линий)
- Подключи [Lenis](https://github.com/darkroomengineering/lenis) для смуз-скролла
- Перенеси в Astro или Next.js, если нужен реальный сайт с маршрутами
- Деплой на Vercel: `vercel` из терминала, через 30 секунд — публичный URL
