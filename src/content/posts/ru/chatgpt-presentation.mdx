# Как сделать презентацию через ChatGPT за 15 минут

Если ты откладываешь презентацию в долгий ящик, потому что не знаешь с чего начать — это не проблема. ChatGPT может придумать структуру, написать текст слайдов и подбросить идеи для визуала. Всё дело в правильном промпте.

В этом гайде я покажу как за 15 минут получить готовую структуру презентации, которую потом оформишь в PowerPoint или Canva. Не придётся думать о том, что написать на каждом слайде.

## Шаг 1: Напиши фундаментальный промпт

Прежде всего расскажи ChatGPT что ты представляешь. Чем точнее описание — тем лучше результат.

```
Помоги мне сделать презентацию для [целевая аудитория].

Название: [Название презентации]
Цель: [Зачем нужна презентация]
Ключевые моменты: [3-5 главных идей которые нужно донести]
Длительность: [Сколько минут отводится на выступление]
Тон: [Formal / casual / educational / persuasive]

Дай мне структуру из 8-10 слайдов. На каждый слайд напиши что писать.
```

**Пример с реальными значениями:**

```
Помоги мне сделать презентацию для руководителей маркетинговых отделов.

Название: "Как AI экономит время маркетологам"
Цель: Убедить их внедрить ИИ-инструменты в работу команды
Ключевые моменты:
- ChatGPT экономит 2-3 часа в день на копирайтинге
- Midjourney убыстряет создание визуалов в 5 раз
- Инструменты не заменяют креатив, усиливают его

Длительность: 20 минут
Тон: persuasive (убеждающий)

Дай мне структуру из 8-10 слайдов. На каждый слайд напиши что писать.
```

ChatGPT выдаст тебе примерно такое:

```
Слайд 1: Title Slide
"Как AI экономит время маркетологам"
Твоё имя, дата

Слайд 2: The Problem
- Маркетологи тратят 2-3 часа в день на рутину
- Копирайтинг, варианты постов, дизайн-брифы
- Время на креатив сжимается

Слайд 3: The Solution
...
```

Скопируй эту структуру себе в документ.

## Шаг 2: Раскрой каждый слайд

Теперь не давай ChatGPT всё сразу. Работай слайд за слайдом. Это займёт больше времени, но результат будет точнее.

Отправь новый промпт:

```
Для слайда [№ слайда] с заголовком "[Заголовок]":

Напиши:
1. Основной текст (2-3 предложения)
2. 3 ключевые пункта (в виде список)
3. Идеи для визуала (что нарисовать, что сфотографировать)
4. Примеры данных или статистика (если нужна)

Помни что слайд должен быть ясным за 10 секунд чтения.
```

**Пример:**

```
Для слайда 3 с заголовком "Сколько экономим времени":

Напиши:
1. Основной текст (2-3 предложения)
2. 3 ключевые пункта (в виде список)
3. Идеи для визуала (что нарисовать)
4. Примеры данных

Помни что слайд должен быть ясным за 10 секунд чтения.
```

Результат:

```
Основной текст:
"Инструменты ИИ экономят команде в среднем 10-15 часов в неделю. 
Это не замена креативу, а усилитель — человек пишет брифф, 
ИИ генерирует варианты, человек выбирает лучший."

Ключевые пункта:
- ChatGPT: 2 часа в день на копирайтинг → 20 минут
- Midjourney: день работы дизайнера → 2 часа
- Результат: больше времени на стратегию и креатив

Идеи для визуала:
- Левая сторона: часы (много времени потеряно)
- Правая сторона: часы (мало времени потеряно)
- Стрелка между ними с логотипами ChatGPT и Midjourney
- Яркие цвета: красный/зелёный контраст

Примеры данных:
"Исследование McKinsey (2024): компании которые внедрили ИИ, 
увеличили производительность на 40% в первый год"
```

Возьми этот текст для слайда.

## Шаг 3: Попроси идеи для каждого визуала

Если ты не дизайнер — не беда. ChatGPT подскажет что рисовать.

```
Для слайда с заголовком "[Заголовок]" нужен визуал.

Контекст: [Что на слайде написано]

Дай мне 3 идеи:
1. Простая (можно сделать в PowerPoint за 2 минуты)
2. Красивая (нужна Canva или Figma)
3. Профессиональная (нужен дизайнер или Midjourney)

Для каждой идеи напиши:
- Что рисовать (описание)
- Какие цвета
- Откуда взять картинку (Unsplash, Midjourney, своё фото и т.д.)
```

Пример:

```
Для слайда с заголовком "The Problem" нужен визуал.

Контекст: маркетологи тратят много времени на рутину, мало на креатив.

Дай мне 3 идеи:
1. Простая (PowerPoint за 2 минуты)
2. Красивая (Canva)
3. Профессиональная (Midjourney)

Для каждой напиши что рисовать, какие цвета, откуда взять картинку.
```

ChatGPT выдаст:

```
1. Простая (PowerPoint):
- На левой стороне слайда поставь картинку "уставший маркетолог" 
  из Unsplash. Ищи по запросу "tired marketer office"
- На правой стороне напиши список задач: email, social posts, 
  design briefs, reports — большой красный шрифт
- Цвета: чёрный текст, красная картинка, белый фон

2. Красивая (Canva):
- Используй Canva шаблон "Problems Slide"
- Левая половина: градиент красный → оранжевый
- На градиент наложи иконки: письмо, соцсеть, дизайн, отчёт
- Правая половина: белая, текст задачи
- Гарнитура: Montserrat (bold) для заголовка, Open Sans для текста

3. Профессиональная (Midjourney):
- Промпт для Midjourney: "Stressed creative professional surrounded by 
  tasks floating in air, vibrant colors, editorial illustration style, 
  modern art, clean composition"
- Цвета: оранжевый, синий, белый
- Используй эту картинку как фон слайда с полупрозрачностью 30%
```

Выбери уровень сложности которой тебе подходит.

## Шаг 4: Собери всё в PowerPoint или Canva

Теперь у тебя есть:
- Структура презентации (от шага 1)
- Текст для каждого слайда (от шага 2)
- Идеи для визуала (от шага 3)

Открой PowerPoint, Canva или Google Slides и начни собирать слайды. На это уйдёт 5-10 минут если ты следуешь текстам от ChatGPT.

**Советы по сборке:**

1. **Не переделывай текст.** Если ChatGPT написал хорошо — копируй как есть. Твоя задача оформить, не переписывать.

2. **Один визуал = один слайд.** Не втискивай 5 картинок на один слайд.

3. **Фон и типографика.** Если используешь Canva — выбери шаблон и придерживайся его стиля. Не микшируй разные шрифты.

4. **Читаемость на расстоянии.** Представь что презентацию смотрят из последнего ряда аудитории. Шрифт достаточно большой?

## Лайфхак: Генерируй примеры и истории

Если на слайде нужен пример или история — дай ChatGPT этот промпт:

```
Для слайда "[Заголовок]" нужен пример или кейс.

Фон: [Что произошло, кто был юзер, какая была проблема]

Напиши короткую историю (100 слов) которая показывает как ИИ решил проблему.

История должна быть:
- Конкретной (реальные числа)
- Простой (как для пятиклассника)
- Интересной (есть конфликт и решение)
```

Это добавит ощущение реальности к твоей презентации.

## Что дальше

Готовую презентацию можно:
- Отправить по email перед встречей
- Поделиться линком в Canva (если делал в Canva)
- Скачать как PDF если нужно распечатать
- Загрузить на Google Drive для совместного редактирования

Если нужно добавить видео или анимацию — это уже другая история. Но за текст и структуру поздравляем — ты сделал за 15 минут то что обычно занимает час.
