# neversleep.chat — Руководство по публикации

neversleep.chat — это блог про ИИ-инструменты для не-разработчиков. Сайт работает как поисковик по задачам: юзер приходит со своей проблемой и находит готовый гайд.

**Это руководство для Anнy и Hermes.** Как быстро добавлять новые посты и публиковать их на сайт.

---

## Как добавить пост

### 1. Создай файл MDX

Файлы постов хранятся в директории `src/content/posts/` разделены по языкам:
- `src/content/posts/ru/[slug].mdx` — русские посты
- `src/content/posts/en/[slug].mdx` — английские посты

Имя файла строится из task ID и slug:
```
[task-id]-[slug].mdx
```

**Примеры:**
- `chatgpt-presentation.mdx` — гайд про ChatGPT для презентаций
- `claude-review.mdx` — обзор Claude
- `canva-design-video.mdx` — гайд про Canva для видео

### 2. Заполни frontmatter

Каждый пост начинается с frontmatter в формате YAML между тройными дефисами `---`.

**Полный шаблон со всеми полями:**

```yaml
---
title: "Название поста"
slug: "slug-без-префикса-task"
description: "Одно предложение что в этом посте. Это будет в meta tags и списке постов."
task: "task-id-из-таблицы-ниже"
tools: ["tool-1", "tool-2"]
type: "guide"
tags: ["tag1", "tag2"]
languages: ["ru"]
date: 2026-04-29
is_editorial: true
---
```

**Объяснение полей:**

| Поле | Обязательно | Что это | Примеры |
|------|-------------|--------|---------|
| `title` | ✅ | Заголовок поста | "Как сделать презентацию через ChatGPT" |
| `slug` | ✅ | URL-friendly идентификатор (без task ID) | "presentation", "review", "full-guide" |
| `description` | ✅ | Короткое описание (1-2 предложения) для preview | "Пошаговый гайд за 15 минут" |
| `task` | ✅ | Из таблицы ниже | "presentation", "article", "social-media-post" |
| `tools` | ✅ | Массив инструментов в lower-kebab-case | `["chatgpt", "claude", "midjourney"]` |
| `type` | ✅ | guide / review / case / list | "guide" или "review" |
| `tags` | ❌ | Теги для фильтрации | `["marketing", "social-media"]` |
| `languages` | ❌ | Языки поста (default: ["ru"]) | `["ru", "en"]` или `["en"]` |
| `date` | ✅ | Дата публикации | 2026-04-29 |
| `is_editorial` | ✅ | Всегда true (на этапе 1 только редакционный контент) | true |
| `source` | ❌ | URL источника если пост по чужому материалу | "https://..." |
| `cover` | ❌ | URL картинки для preview | "https://..." |

**Правила для инструментов (tools):**

Используй официальное имя инструмента в lower-kebab-case:
- `chatgpt` (не ChatGPT, не chat-gpt)
- `claude` (не Claude, не anthropic)
- `midjourney` (не MidJourney)
- `canva` (не Canva)
- `figma` (не Figma)

### 3. Напиши контент

После frontmatter пиши обычный Markdown/MDX контент.

**Длина:** 600-900 слов для гайда, 500-700 для обзора.

**Требования по стилю (смотри SOUL.md):**

- На "ты" (только для русских постов)
- Прямой, конкретный стиль — без воды и общих слов
- Нумерованные шаги в гайдах
- Промпты в код-блоках (` ``` `)
- Только то, что ведёт к действию
- Проверь: можно ли это повторить прямо сейчас?

### 4. Коммит и пуш

```bash
# Добавь файлы постов
git add src/content/posts/

# Коммит с понятным сообщением
git commit -m "Add posts: chatgpt-presentation (ru+en), claude-review (ru)"

# Пуш на GitHub
git push
```

### 5. Автодеплой

Vercel автоматически отслеживает ветку `main`. Когда ты делаешь push:
1. Vercel видит коммит с новыми файлами
2. Запускает build процесс (~30 сек)
3. Деплоит сайт на neversleep.chat

**Новые посты появляются на сайте через 30-60 секунд после push.**

## Группы задач и task IDs

Каждый пост про одну из этих категорий задач. Выбери нужную и используй task ID в frontmatter.

### Text (Текст)
Работа с текстом: посты, статьи, письма, копирайтинг, переводы.

| Task ID | Описание |
|---------|----------|
| `social-media-post` | Пост в соцсети (инстаграм, ТГ, Twitter и т.д.) |
| `article` | Статья, длинный текст, блог-пост |
| `email` | Email письма, newsletter, рассылки |
| `copywriting` | Продающие тексты, заголовки, описания |
| `translation` | Перевод текстов на другие языки |

### Visual (Визуал)
Картинки, видео, дизайн, фото, презентации.

| Task ID | Описание |
|---------|----------|
| `generate-image` | Генерация изображений (промпты, стили) |
| `create-video` | Создание видео, редактирование |
| `presentation` | Презентации, слайды |
| `design` | Дизайн макетов, графики, баннеры |
| `photo-edit` | Редактирование фото, обработка |

### Work (Работа)
Исследования, анализ, суммаризация, транскрибация.

| Task ID | Описание |
|---------|----------|
| `research` | Исследование темы, поиск информации |
| `transcribe` | Транскрибация видео/аудио в текст |
| `analyze-doc` | Анализ документов, таблиц, данных |
| `summary` | Суммаризация текстов и документов |

### Automate (Автоматизация)
Боты, workflow, скраперы, уведомления.

| Task ID | Описание |
|---------|----------|
| `chatbot` | Чат-боты и виртуальные ассистенты |
| `workflow` | Автоматизация процессов и workflow |
| `scraper` | Сбор данных, парсинг |
| `notification` | Уведомления, оповещения, рассылки |

### NoCode (Без кода)
Создание лендингов, веб-приложений, инструментов без кода.

| Task ID | Описание |
|---------|----------|
| `landing` | Лендинг, одностраничный сайт |
| `web-app` | Веб-приложение, сервис |
| `internal-tool` | Внутренний инструмент, админ-панель |

## Типы постов

Выбери `type` в зависимости от формата:

### guide
Пошаговый гайд "как сделать X с помощью Y".

**Структура:**
- Введение (что будем делать, зачем)
- Пошаговые инструкции (нумерованные)
- Примеры (промпты, скриншоты)
- Советы и лайфхаки
- Куда дальше (что делать дальше)

**Длина:** 600-900 слов

**Примеры:**
- "Как сделать презентацию через ChatGPT"
- "Как использовать Claude для анализа документов"

### review
Обзор инструмента: что это, что умеет, сколько стоит, кому подойдёт.

**Структура:**
- Что это (в одном предложении)
- Основные фичи (самые важные 3-5)
- Стоимость и планы
- Для кого подойдёт
- Для кого НЕ подойдёт
- Как начать (quickstart)
- Чем отличается от аналогов
- Вердикт (коротко)

**Длина:** 500-700 слов

**Примеры:**
- "Claude — ИИ для глубокой работы с текстом"
- "ChatGPT vs Claude: что выбрать"

### case
Кейс-стади: реальная история использования, цифры, результаты.

**Структура:**
- Задача (какая была проблема)
- Решение (как использовали ИИ)
- Результаты (цифры, метрики)
- Уроки и выводы

**Длина:** 600-900 слов

### list
Подборки, топ-5, сравнение, аннотированный список.

**Структура:**
- Критерии выбора (почему именно эти)
- Список с описаниями
- Таблица сравнения
- Рекомендация

**Длина:** 600-900 слов

## Чек-лист перед публикацией

Перед тем как делать `git push`:

- [ ] Frontmatter полный и корректный (все обязательные поля есть)
- [ ] `task` есть в списке ниже
- [ ] `tools` в lower-kebab-case
- [ ] `type` один из: guide / review / case / list
- [ ] `date` текущая дата (2026-04-29)
- [ ] Контент 600-900 слов (или по требованиям типа)
- [ ] Нет AI-штампов ("обратите внимание", "следует отметить", и т.д.)
- [ ] Нет пустых заголовков или расплывчатого введения
- [ ] Всё про действие, не про теорию
- [ ] Инструкции повторяемые прямо сейчас

## Вопросы и проблемы

**Вопрос:** Могу ли я добавить реферальную ссылку?
**Ответ:** Только с согласованием Анны.

**Вопрос:** Что делать если task ID не подходит?
**Ответ:** Выбери ближайший. Если ни один не подходит — спроси у Anny.

**Вопрос:** Можно ли писать о себе в посте?
**Ответ:** Нет. Пост про инструмент и задачу, не про Hermes.

**Вопрос:** Как часто обновляется сайт?
**Ответ:** Сразу после push. Vercel деплоит ~30 сек.
